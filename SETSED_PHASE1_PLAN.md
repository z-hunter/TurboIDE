# Первый этап заимствования из SetsEd

Дата: 2026-10-02. Основа — [REFERENCE_SETSED_REVIEW.md](REFERENCE_SETSED_REVIEW.md).
Права на SetsEd позволяют копировать код и интерфейс. Критерий этого этапа —
минимальная интеграция с текущим `SyntaxEditor : TFileEditor` и сохранение
нынешних UTF-8, undo, сохранения файлов и окон TurboIDE.

## Что входит

| Порядок | Функция и UI | Что брать из SetsEd | Что меняется при переносе | Готовый результат |
| --- | --- | --- | --- | --- |
| 1 | Всплывающий список у курсора | `mainsrc/completi.cc`: `TCompletionBox`, `TNoFrame`, позиционирование над/под курсором, one-result auto-accept, поиск набором текста | Подключить к современной `TSortedListBox`/`TStringCollection`, заменить `TCEditor::isSymbol` на проверку символов текущего редактора, учесть границы экрана и UTF-8 | Один общий chooser для PMacros сейчас и TAGS completion позже; управление стрелками, Enter, Esc и продолжением ввода. |
| 2 | PMacros и выбор из списка | `mainsrc/pmacros.cc`, `TCEditor::SearchPMTrigger`/`ExpandMacro`/`ExpandPMacro`, `mainsrc/deedidia.cc:createPMChoose` и диалог переменных; файлы `cfgfiles/pmacros.pmc`, `cpmacros.pmc` | Старые коллекции и `EasyDiag` заменить стандартными диалогами Turbo Vision, исполнение связать с `TFileEditor`; читать `Mode`, но реализовать только применимые к текущему редактору режимы, явно сообщать о неподдерживаемом содержимом | Реализовано: точные два символа раскрываются напрямую; при несовпадении показывается список по первой букве даже при одном кандидате; пустой триггер и пункт **Choose snippet…** открывают полный список. Точный доступный триггер перед курсором подсвечивается, Expand назначен на `Ctrl+P`. Работают переносы строк, backspace, smart tab, `@0`, `@@`, `@{name;default}`; `@1`–`@3` пропускаются как невидимые маркеры. |
| 3 | Парные скобки | `TCEditor::SearchMatchOnTheFly`, `SearchOpenSymbolXY`/`SearchCloseSymbolXY`; UX подсветки пары и команды перехода | Сканировать текущий `TFileEditor` по offset, пропускать комментарии и строки через уже существующий `tokens_` в `src/syntax.cpp`, рисовать атрибут поверх текущей подсветки | `{}`, `[]`, `()` подсвечиваются при курсоре на скобке; jump ведёт к паре. Нет ложных пар внутри строк и комментариев. |
| 4 | Обычный и C/C++ отступ | Обычный `autoIndent` уже находится в современном `TEditor::newLine`; из SetsEd брать поведение `AnalizeLineForIndent` как ориентир | Добавить C/C++ правило после `{` на Enter и уменьшение отступа при вводе `}` в начале строки; использовать уже имеющиеся tokens и размер tab из настроек | Обычный отступ работает без порта; C/C++ режим добавляет уровень после `{` и уменьшает его перед `}`. |
| 5 | Запись и повтор макроса | `TCEditor` в `mainsrc/ceditor.cc`: `cmcRecordMacro`, `cmcStopMacro`, `cmcPlayMacro`, `MacroArray`; UX трёх команд меню | Записывать команды и введённый текст через `SyntaxEditor::handleEvent`, не копировать `keytrans.cc` и генератор Lisp-кода; ограничить длину, запретить рекурсивное воспроизведение | Record / Stop / Play в меню Edit, повторяемый ввод и редакторские команды, понятная индикация записи; один replay не размножает события в записи. |

Первый срез этого плана уже реализован в `SyntaxEditor`. Общий chooser
используется PMacros и в будущем может пригодиться для TAGS. Копирование UI означает
сохранить его размеры, расположение, клавиатурное поведение и подписи там,
где это подходит текущему меню. Даже `TCompletionBox` требует двух точечных
адаптаций: в новой `TSortedListBox` `searchPos` стал private, а у
`TStringCollection` нет старого `setOwnerShip`. `createPMChoose` и Class Browser используют
старый `EasyDiag` (`TSViewCol`, `TSSortedListBox`, `TGrowDialogZ`), поэтому
готовые классы диалогов целиком не копируются; их экран собирается из уже
используемых в TurboIDE `TDialog`, `TListBox` и `TButton`.

## Граница этапа

- `SyntaxEditor` сейчас создаётся только для C/C++ файлов. Переносимые команды
  редактора в этом этапе работают в C/C++; глобальные шаблоны для остальных
  типов файлов потребуют создания того же editor subclass для всех файлов.
- `cfgfiles/cpmacros.pmc` содержит команды `\n`, `\b`, smart tab и маркеры
  `@1`–`@3`. Простая вставка всего body одним `insertText` не воспроизведёт его
  поведение. Шаблоны `f(`, `i(` и `ma` должны раскрывать текст и ставить курсор
  по `@0`; дополнительные маркеры `@1`–`@3` пропускаются, переход по ним
  пока не реализован. Формат ввода переменных поддержан, хотя в штатном
  `cpmacros.pmc` нет шаблона с переменной.
- Запись макросов ограничивается событиями редактора. Меню приложения,
  файловые операции и запуск программы в запись не входят.
- Lisp-вставки `@{(...)}` в наборах `docbook.pmc` и `vhdl.pmc` требуют
  скриптового движка. Для новых скриптов выбран Lua; поддержка этих старых
  выражений не входит в первый этап и не должна исполняться как обычный текст.

## Следующий этап

`mainsrc/tags.cc` совмещает parser Exuberant Ctags, модель символов и диалоги
Class Browser. Его нельзя добавить малым копированием. Сначала нужен один
индекс символов для Universal Ctags; затем на общем chooser появится word
completion, а диалог Class Browser можно повторить по структуре окон SetsEd.
Полный `.shl` highlighter затрагивает renderer старого `TCEditor` и не входит
в этот этап. Прямоугольное выделение добавлено как режим через Ctrl+K.

## Порядок интеграции

1. Chooser + PMacros и их диалоги. Результат виден сразу и повторно использует
   ресурсные `.pmc` SetsEd.
2. Скобки + C/C++ отступ. Оба используют текущий `SyntaxEditor` и его токены.
3. Record / Stop / Play. После появления редакторских команд можно записывать
   и воспроизводить действия из пунктов 1–2.

Перед началом реализации нужны короткие ручные сценарии для каждого пункта:
открыть C-файл, выполнить команду, проверить текст/курсор/undo, затем
сохранить и вновь открыть файл. Для chooser проверить малый экран и ввод
символа после выбора; для макросов — отмену диалога и повтор после Stop.

## Выполненные follow-up задачи

- **Точное поведение PMacro и видимый триггер.** Реализована семантика
  `TCEditor::ExpandMacro`/`SearchPMTrigger`: два символа перед курсором дают
  прямое раскрытие только при точном совпадении; один символ открывает список
  триггеров на эту букву; пустая позиция открывает полный список. Не выбирать
  автоматически единственный кандидат по первой букве для двухсимвольного
  несовпадения (`if` больше не раскрывается напрямую как `i(`). Доступный
  точный триггер перед курсором подсвечивается ярко-синим фоном; раскрытие есть
  в меню, по `Ctrl+P` и через отдельный полный список.
- **Prefix-команды Ctrl+Q и Ctrl+K.** Добавлены последовательности команд
  SetsEd, краткая обычная подсказка `^Q Quick` / `^K Block` и временная
  контекстная строка. `?` листает страницы сокращённых подсказок; Esc отменяет
  префикс. Ctrl+K включает прямоугольную область и её copy/paste/delete/clear,
  hide, move, а также команды блоков и чтения/записи файла.
- **Переход к строке.** Добавлена команда Edit → Go to line… с `Ctrl+J`.
