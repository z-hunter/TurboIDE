# Free Pascal IDE source reference

This folder contains selected upstream Free Pascal IDE sources for local UI and workflow analysis. Files are copied verbatim from `fpc/FPCSource`, `packages/ide`, revision `3e6a1a0dffbeeb0f91a425a558b24036c6a318d7` (2026-10-01). Upstream: https://github.com/fpc/FPCSource/tree/3e6a1a0dffbeeb0f91a425a558b24036c6a318d7/packages/ide

Included files cover the IDE menu/event routing, message and compiler windows, message navigation, palette definitions, and debugger/compiler integration. Their original notices are retained. See [LICENSE](LICENSE) for the upstream Free Pascal license and exception. These files are reference material; TurboIDE does not build or link them.
