# Отчёт: этап 1

## Выполнено

- Вместо окна-заглушки подключён редактор Turbo Vision `TEditWindow`/`TFileEditor`.
- Добавлены New/Open, Save/Save As, стандартные запросы при закрытии изменённого документа, ошибки чтения/записи.
- Open проверяет UTF-8 имя через `CreateFileW`, чтобы отказ доступа или отсутствующий путь не открывался как пустой файл.
- Добавлены меню File/Edit/Search/Windows/Run/Debug, строка состояния, окна документов, поиск/замена, штатный Undo и команды системного clipboard.
- Run/Compile/Debug пока показывают сообщение о будущих этапах; запуск пользователя и отладка здесь не реализуются.
- Сохранён pinned Turbo Vision из существующего CMake FetchContent. Изменения кода ограничены `src/main.cpp`.

## Проверено

- Сборка Release MSVC x64:
  `cmake --build .build/pinned-prototype --config Release --target turboide`
- `turboide.exe` запустился в псевдоконсоли; видны меню, пустой редактор, строка состояния и сине-белая палитра.
- `Alt-X` завершил приложение с кодом 0 и восстановил экран псевдоконсоли.
- Пользователь собрал и запустил IDE вручную, подтвердил работу интерфейса и буфера обмена Windows. Тип терминала и подробный набор проверенных команд не уточнялись.
- При ревизии перед этапом 2 исправлена подсвеченная буква меню Debug для `Alt+D`; Release-сборка после правки прошла.

## Осталась ручная приёмка

Отдельно не подтверждены Unicode-текст, русские имена файлов и путей, LF/CRLF, Cancel/Discard при закрытии и поведение в обоих типах терминала. Буфер обмена подтверждён пользователем, но Unicode-содержимое в нём отдельно не проверялось. Файловые диалоги Turbo Vision ограничены `MAXPATH=260` байтами. Undo доступен в однократном виде; Redo нет.
